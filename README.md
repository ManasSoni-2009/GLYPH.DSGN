# GLYPH_DSGN

GLYPH_DSGN is a client-side retro-tech art generator for text and uploaded images. It turns text into ASCII, ANSI, PETSCII, Braille, Morse, Matrix, glitch, and typeblock compositions, and converts images into pixel, dither, film, glitch, halftone, thermal, stained glass, comic, and print-style treatments.

## Features

- React 18 + Vite + Tailwind CSS
- Canvas-only image processing, with no backend calls
- 25 text and image art styles
- Hardware-inspired control deck with density, grain, bloom, chromatic, palette, and animation controls
- PNG, TXT, SVG, copy-to-clipboard, history restore, and URL hash sharing
- Mobile-friendly modular layout

## Run Locally

```bash
npm install
npm run dev
```

On Windows PowerShell with script execution restrictions, use:

```bash
npm.cmd install
npm.cmd run dev
```

## Build

```bash
npm run build
```
